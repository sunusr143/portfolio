# Sunu Mohan: Freelance Portfolio and Client Acquisition Site

Next.js 14 (App Router) + TypeScript + Tailwind CSS. Built to win freelance AWS, EKS, Terraform, CI/CD and DevSecOps projects.

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in values (see below)
npm run dev                  # http://localhost:3000
npm run typecheck && npm run lint && npm run build
```

Requires Node 18.18+.

## Edit content (no UI code changes)

| What | File |
| --- | --- |
| Availability, contact details, headline, pricing note | `content/site.ts` |
| Home hero text, tools strip, optional photo (`photo`) and GitHub link (`github`) | `content/site.ts` |
| Services | `content/services.ts` |
| Case studies and diagrams | `content/projects.ts` |
| Engagements (add `price` to show pricing) | `content/engagements.ts` |
| Skills, certifications, career | `content/skills.ts` |

Availability: set `availability.status` to `available`, `limited` or `unavailable`.

## Command palette

Press Ctrl+K (or Cmd+K), or use the Search button in the header, to jump to any page, project, service or contact action. It is built automatically from the content files, so new projects and services appear in it with no extra work (`lib/palette.ts`).

## Adding a project

Open `content/projects.ts`, copy the commented template at the bottom of the `projects` array, and fill it in with true details only. Save and it shows up on the projects page, filters and sitemap automatically. Optional sections (stack, challenges, impact, diagram) are hidden when left out. Keep employer and client details sanitized.

## Inquiry form delivery

**Quickest free setup (no domain):** get a free access key at [web3forms.com](https://web3forms.com) and set `WEB3FORMS_ACCESS_KEY`. Inquiries are emailed to the address you registered. Only name, email and a short message are required from visitors.

`POST /api/inquiry` validates input (zod), applies a honeypot, a best-effort rate limit and optional Cloudflare Turnstile, then sends email through [Resend](https://resend.com).

1. Create a Resend account and verify a sending domain.
2. Set `RESEND_API_KEY`, `INQUIRY_FROM_EMAIL`, `INQUIRY_TO_EMAIL`.
3. (Recommended) Create a Cloudflare Turnstile widget and set `NEXT_PUBLIC_TURNSTILE_SITE_KEY` and `TURNSTILE_SECRET_KEY`.

If the email variables are missing, the API returns HTTP 503 and the form shows an error with a direct email link. It never reports success without delivery. The in-memory rate limit is per server instance; use a shared store or your host's WAF for strict limits. No database is needed.

## Deploy

Vercel works out of the box: import the repo, add the environment variables, set `NEXT_PUBLIC_SITE_URL` to your domain. Any Node host works with `npm run build && npm start`.

## Verification status

The source was written and type-checked only partially in an offline environment. Run `npm ci && npm run typecheck && npm run lint && npm run build` once before deploying; the included GitHub Actions workflow (`.github/workflows/ci.yml`) runs the same checks on every push. `package-lock.json` is generated by your first `npm install`; commit it so CI (`npm ci`) works.

## Before you publish

- Review `content/projects.ts` with your employer's confidentiality rules in mind.
- Set `NEXT_PUBLIC_SITE_URL` so the sitemap, canonical URLs and social cards are correct.
